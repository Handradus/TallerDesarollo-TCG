# 📦 Proyecto Pokémon Scraper

Este proyecto permite buscar cartas Pokémon por nombre o número de serie, accediendo a información desde una base de datos local y complementándola con datos de la API de Pokémon TCG.

## 🚀 Tecnologías utilizadas

### Backend (Node.js + Express + TypeORM + MySQL/PostgreSQL)

- express: Framework web para construir la API.  
- typeorm: ORM para interactuar con la base de datos.  
- mysql2 / pg: Driver de base de datos (dependiendo del motor que uses).  
- dotenv: Manejo de variables de entorno.  
- cors: Para permitir solicitudes entre frontend y backend.  
- jsonwebtoken: Para autenticación por token.  
- passport-google-oauth20: Para login con cuenta de Google.  
- axios: Para llamadas a la API de Pokémon TCG.  

### Frontend (React)

- React + Vite para construcción de UI rápida.  
- axios para consumo de API.  
- react-router-dom para navegación.
