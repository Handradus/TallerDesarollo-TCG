# 📦 Proyecto Pokémon Scraper

Este proyecto permite buscar cartas Pokémon por nombre o número de serie, accediendo a información desde una base de datos local y complementándola con datos de la API de Pokémon TCG.

## 🚀 Tecnologías utilizadas

### Backend (Node.js + Express + TypeORM + MySQL/PostgreSQL)

- express
- typeorm
- pg 
- doten
- cors  
- jsonwebtoken
- axios

### Frontend (React)

- React + Vite .
- axios
- react-router-dom
